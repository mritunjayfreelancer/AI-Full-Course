Concept 01

Internet कैसे काम करता है?

Internet दुनिया भर के interconnected networks का एक विशाल system है, जो अलग-अलग devices को आपस में बात करने और data share करने की अनुमति देता है।

Request & Response Workflow

आपका device (Client) internet के through किसी server को request भेजता है, server उस request को process करके data वापस आपके browser को भेजता है।

Concept 02

Website कैसे खुलती है?

जब आप browser में कोई URL टाइप करते हैं, तो browser domain name system (DNS) की मदद से server का पता लगाता है और वहां से webpage के files (HTML, CSS आदि) download करके आपके सामने display करता है।

Concept 03

Search Engine क्या है?

Search engine (जैसे Google) एक software system है जो internet पर मौजूद millions of web pages को index करता है और आपकी query के आधार पर सबसे सही results सामने लाता है।

💡
Browser vs Search Engine

Browser वह software है जिससे आप internet चलाते हैं (जैसे Chrome, Firefox), जबकि Search Engine वह website है जिससे आप info खोजते हैं (जैसे Google, Bing)।

Concept 04

URL, Domain और Hosting क्या हैं?

Term Meaning Example
URL Uniform Resource Locator (पूरा web address) https://example.com/page.html
Domain Website का नाम या पहचान example.com
Hosting Server जहाँ website की files स्टोर रहती हैं Cloud Servers / Web Host
Concept 05

Download और Upload का मतलब

  • Download: Internet से किसी file को अपने device पर लाना।
  • Upload: अपने device से किसी file को internet पर (cloud या server पर) भेजना।
Concept 06

Online Accounts और Privacy

आज लगभग हर digital service के लिए account की जरूरत होती है। अपनी personal information और data को safe रखने के लिए privacy settings को समझना जरूरी है।

Concept 07

Password और Account Security

Strong passwords का उपयोग करें, अलग-अलग accounts के लिए अलग passwords रखें, और जहाँ संभव हो Two-Factor Authentication (2FA) enable करें।

⚠️
Security Warning

कभी भी अपने passwords या API keys को public repositories या अनtrusted websites पर साझा न करें।

Concept 08

Cloud Storage क्या है?

Cloud storage (जैसे Google Drive, OneDrive) आपको internet के माध्यम से अपनी files को remotely store और access करने की सुविधा देता है, जिससे आप किसी भी device से अपना data देख सकते हैं।

Concept 09

PDF, Word और Excel Files

Digital work में documents के अलग-अलग formats काम आते हैं:

  • PDF: Document formatting को lock रखने और आसानी से पढ़ने के लिए।
  • Word: Text notes और reports लिखने और एडिट करने के लिए।
  • Excel: Data tables, calculations और records संभालने के लिए।
Concept 10

AI सीखने के लिए जरूरी Digital Skills

AI tools का बेहतरीन उपयोग करने के लिए आपको browser navigation, file management, cloud tools और basic document handling में confident होना चाहिए।
